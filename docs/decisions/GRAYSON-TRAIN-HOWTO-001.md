# GRAYSON-TRAIN-HOWTO-001 — how to do every library exercise, with a free video link (owner go, 2026-11-24)

Gavin merged the [brief](../agent/GRAYSON-TRAIN-HOWTO-001.md) (#657), which approves these defaults. Backlog B5.

- **Own words only.** Every guide (role, setup, three cues, one or two mistakes, one alternative) is written fresh in
  plain words from general training knowledge. Nothing is copied from MuscleWiki, ACE or any other source. The ten
  calibration-preview guides moved into `domain/workout/exerciseHowTo.ts` unchanged; it is the one source.
- **ACE as the link source, and why.** ACE's Exercise Library is free, needs no sign-in, gives one page per exercise
  and is run by a certifying body. Video and photos stay on ACE's site behind a link; nothing is embedded.
- **The link rule.** A link only where its ACE page was opened and shows the same movement (equipment may differ;
  the PR table flags those). No match, no link; never a search link or a guessed address. All links use
  `https://www.acefitness.org/resources/everyone/exercise-library/<n>/<slug>/`. 40 of 54 have one; 14 don't
  (13 no matching page, deadlift unverified because its page errored).
- **His to change.** EDIT changes the setup, cues, mistakes and link for one exercise; his version wins; RESET brings
  the bundled text back. `beyond.exerciseHowTo.v1`, travelling with the backup as "Exercise how-to edits". The role
  line and the alternative aren't editable yet.
- **Where.** HOW TO beside each library row (MORE → EXERCISE LIBRARY → ADD EXERCISE) and beside the current
  exercise in TRAIN's live workout; the sheet opens over the workout and rest keeps counting.
