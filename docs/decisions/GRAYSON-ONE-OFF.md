- **EMPTY WORKOUT** on TRAIN (and **START EMPTY** on TODAY) starts a STANDARD session with no routine, through the
  same RED-capacity check and in-flight guard as any start. He adds exercises with WORKOUT-CHANGES' ADD EXERCISE.
- **A one-off never moves the A, B, C turn:** it's left out of the rotation's "last advancing session", and a programme
  sequence only ever advances on its own members. History calls it "Workout (one-off)".
- **SAVE AS ROUTINE** on its finish summary, only when he taps it: each exercise done, in the order done, with the
  working sets done, its rep range and his remembered rest; named by the main muscle groups and the date ("Arms · Nov
  25"), editable. UNDO archives it. It isn't added to his programme (WEEK-PLAN places routines on days).
- **TODAY:** on a planned day the card's START begins that workout and shows it live; START EMPTY is the quieter second
  button; on a "not today" day START EMPTY stays one tap away. TRAIN's own START path does the work, so the RED
  override question, an open session (resumed, never doubled) and a sequence needing review behave as on TRAIN.
