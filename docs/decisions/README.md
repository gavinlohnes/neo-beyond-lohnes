# Decision entries (from 2026-11-23)

One file per locked product or UX decision, named by its ID (for example `LOG-WHEN-002.md`), so parallel work never
conflicts in one shared log (DEV-FLOW-002 amendment, Gavin, 2026-11-23). Entries up to that date stay in
[`../UX_DECISIONS.md`](../UX_DECISIONS.md), which remains the canonical register for them and points here.

Each file: the ID and title with the owner's words and date, the rules decided, and links to the brief and PR. A later
change to a decision amends its own file (or names the file it amends); it is never silently rewritten.
