# Decision entries

The Decision Register is [`../UX_DECISIONS.md`](../UX_DECISIONS.md) plus this folder, with equal authority (AGENTS.md
authority order, item 3). Decision entries recorded after the DEV-FLOW-002 amendment merges (#624) go here, one file
per locked product or UX decision named by its ID (for example `LOG-WHEN-002.md`), so parallel work never conflicts in
one shared log. Every earlier entry, including those dated 2026-11-23, stays in `UX_DECISIONS.md`.

Each file: the ID and title with the owner's words and date, the rules decided, and links to the brief and PR. A later
change to a decision amends its own file (or names the file it amends); it is never silently rewritten.
