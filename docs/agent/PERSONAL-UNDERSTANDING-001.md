## Outcome

In MORE → Review, an optional Personal Understanding workspace connects explicit priorities,
selected targets and written lessons with existing personal baselines and comparable rotation
positions. Separate operator choices from observations. Reveal dates, source records, sample sizes,
unknowns and existing correction/edit routes. Never imply a personality judgment, diagnosis,
causal discovery or a new recommendation. This first slice makes the existing knowledge usable;
it does not introduce inferred preferences or claim a complete model of Gavin.

## Scope and boundaries

- Existing active Missions, explicitly set optional targets, reviewed written lessons, personal
  baseline readings and rotation-position comparisons, all derived afresh from canonical sources.
- Reuse the existing journal matcher to expose candidate lessons beside Missions, labelled as
  word matches rather than confirmed relationships, recommendations or inferred preferences.
- Bounded lists, meaningful empty/loading/error states, re-entry refresh, phone accessibility,
  human-readable dates and direct inspection/correction navigation.
- No Engine edits, schema/events/commands, backup changes, new preference store, AI/provider,
  dependency, automatic plan changes, priority changes, TODAY/primary-navigation changes,
  spending, or takeover of Claude's SLEEP-ENGINE-001 (#300).
- Future feedback, experiments and recommendation inputs require separately bounded scope.
