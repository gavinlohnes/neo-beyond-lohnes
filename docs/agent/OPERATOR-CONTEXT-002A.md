## Outcome and scope

One read-only, source-aware projection of existing current records. Planning, automatic briefs and record inspection share assembly and per-category coverage. Source types distinguish operator statements, recorded events, measurements, forecasts and deterministic derivations. Projects/routines gain source inspection. Existing sharing defaults and card/atomic guards stay intact. Local LIFE → Memory exposes the same context with bounded inspection, existing canonical editors and honest legacy-memory labels.

Selected personal context fails closed. Unavailable non-personal categories are explicitly unavailable, never empty. The complete serialized source payload is bounded, with omissions/excerpts disclosed and no uncapped prose bypass. Read assembly uses a local read transaction; no projection store, migration or writes. Corrected/removed personal context invalidates model history as before; current operational revisions must not masquerade as fresh old transcript evidence.
