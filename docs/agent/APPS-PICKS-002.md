# APPS-PICKS-002: eight proven ideas, BEYOND's own way

- **Authorization:** Gavin, 2026-11-07. From a list of 35 ideas from other apps and open-source projects he
  picked **1, 8, 9, 3, 16, 23, 10, 33**. None of them was marked as crossing a Protected boundary.
  Builder: Claude Code. One PR per pick, each with independent exact-head review and green CI.
- **Boundaries for every pick:** BEYOND's own implementation of a proven pattern, built from existing records and
  commands. No new stored data type, schema, dependency, provider, Engine or recommendation change, and no TODAY
  change. Anything that saves still goes through a confirm card or an existing command.

| Order | Pick | Pattern from | What BEYOND gets |
|---|---|---|---|
| 1 | 8 Tappable links | Obsidian, Logseq | Connections entries and [[link]] mentions open the record (task, project, day, journal, highlight). |
| 2 | 9 Person pages | Clay, Monica | [[Name]] opens a page: saved dates and facts about that person, plus everything linking to them. A person is a name, so two people sharing a first name share a page for now. |
| 3 | 1 Quick add | Todoist, Things | "dentist Tue 3pm" becomes a dated task card to confirm, parsed on the phone. |
| 4 | 3 End-of-shift shutdown | Sunsama | Done today, move to tomorrow, one line for the note. |
| 5 | 16 Plate calculator | Strong, Hevy | Plates per side for a target weight. |
| 6 | 23 Year in pixels | Daylio, GitHub | One square per recorded day, colored by energy or sleep; no streaks. |
| 7 | 10 Daily resurfacing | Readwise | One saved highlight or an older daily note each day. |
| 8 | 33 Plan my day off | Motion, Reclaim | Alfred drafts a day-off plan from your tasks, calendar and recovery, saved only by confirming. |

**Leverage gate.** REUSE: each pick's named pattern, plus BEYOND's existing Connections, people, intent commands,
workout data, Whole Picture rows, highlights and Alfred proposal cards. OWN: the BEYOND-specific mapping.
BUILD FROM SCRATCH: none.
