# VCC-001 // TODAY State Rail

## Mission

Replace TODAY's existing status strip with one compact State Rail that strengthens the command-
center hierarchy while preserving all existing truth, controls, recommendation authority, and
behavior. Owner authorized 2026-10-07; this contract records the agreed scope before implementation.

## Approved baseline

`origin/master` at `87a4e128c41d8788a6f75f3ed27efa3531272450`, verified via
`git fetch origin master && git rev-parse origin/master`. Implementation must launch only while
freshly fetched `origin/master` still equals this exact SHA.

## Risk classification

ARCHITECTURAL. This replaces a load-bearing TODAY composition surface and changes how existing
operational state, phase, and provenance are composed, without changing their meaning or sources.
It does not authorize Engine, recommendation, domain, persistence, event, or schema changes.

## Authorized scope

- Replace TODAY's existing status strip in the same position and footprint with one compact State
  Rail. Lead with the current operational state and retain System Status as a subordinate explicit
  reading.
- Add a compact `BEFORE → SHIFT → AFTER → OFF` phase line driven only by the existing
  `deriveShiftClockView` result. UNKNOWN highlights nothing.
- Add one closed-by-default `INTELLIGENCE` disclosure containing only existing work-context
  provenance, System Status reasons, and the current phase/countdown basis.
- Use existing motion tokens for 150–220 ms state/disclosure transitions. No bounce, loop, or
  decorative animation. Reduced motion must be effectively instant.
- RED may illuminate the rail only when existing System Status is RED. AMBER uses the existing
  warning treatment. GREEN and NO READ stay neutral. State meaning is always written in text.
- Add targeted real-browser and unit/integration coverage needed by the acceptance criteria, and
  capture phone screenshots for GREEN, AMBER, RED, UNKNOWN, expanded intelligence, and reduced
  motion.
- Expected implementation footprint: `src/ui/screens/today/**`, the narrowly scoped State Rail
  styles in `src/ui/styles/global.css`, and directly relevant tests/screenshots. Application code
  may be read but not semantically changed; any required semantic change is a STOP condition.

## Required invariants

- All displayed state is derived from existing authoritative values. UNKNOWN never guesses.
- `deriveShiftClockView` remains the sole phase/countdown source used by the State Rail.
- Existing System Status thresholds, reasons, wording truth, and Engine isolation remain unchanged.
- The disclosure is read-only and closed by default; opening it writes no domain or persistence
  state and reveals only already-available provenance/basis.
- The State Rail replaces the existing status strip; it does not add a TODAY phase row or increase
  the dominant-surface count.
- Red remains exclusive to the existing RED System Status semantics; AMBER uses the existing
  warning treatment; GREEN and NO READ remain neutral; text always conveys meaning without color.
- Existing controls remain present, reachable, and behaviorally unchanged.
- Minimum rendered text is 16 px, interactive targets are at least 44 px, supported narrow widths
  do not overflow, and contrast meets WCAG AA.

## Acceptance criteria

1. Targeted tests exercise BEFORE, SHIFT, AFTER, OFF, and UNKNOWN; UNKNOWN highlights no phase.
2. Targeted tests exercise RED, AMBER, GREEN, and NO READ with their authorized treatments and
   explicit text; only RED illuminates the rail red.
3. `INTELLIGENCE` is closed by default, opens with only existing work-context provenance, System
   Status reasons, and phase/countdown basis, and is read-only.
4. State and disclosure transitions use existing 150–220 ms motion tokens; reduced motion is
   effectively instant, with no bounce, loop, or decorative animation.
5. Browser tests prove no additional TODAY phase row and an unchanged dominant-surface count.
6. Browser tests prove no horizontal overflow at 320, 360, and 412 CSS px; every new control is at
   least 44 px; rendered text is at least 16 px; color treatments meet WCAG AA.
7. Phone screenshots exist for GREEN, AMBER, RED, UNKNOWN, expanded intelligence, and reduced
   motion and show the real application state.
8. No diff touches Engine, recommendation, domain, persistence, schema, backup, event semantics,
   dependencies, tabs, other primary screens, REPORT-001, or WEEKAHEAD-001.
9. The contract's targeted suites, `npm run verify`, `npm run check:risk --
   87a4e128c41d8788a6f75f3ed27efa3531272450`, and `git diff --check` pass before PR handoff.
