# GYM-001 // GYM SCREEN

## Mission

A full-screen gym view of the current lift during an active TRAIN workout, built for using one
hand between sets. Owner brief 2026-10-04 (parking lot "Gym mode") moved into the Queue with
rulings 1A (split; this Drop is the screen) and 3A (the warm-up ramp is a suggestion).

## Approved baseline

`origin/master` at `b58fbaf2a827ce15a25513e008d90ec600d42f48`.

## Risk classification

ARCHITECTURAL: changes how a set is logged during a workout (a new full-screen mode over the
existing TRAIN session). It reuses TRAIN's existing state and commands (logSet, rest, skip);
no Engine, domain, persistence, schema or dependency change. Gavin approves the merge.

## Authorized scope

- `src/ui/screens/train/GymMode.tsx` (new) and a GYM MODE button in TRAIN's active STANDARD or
  REDUCED workout. Gym mode covers the screen (above the bottom nav) until EXIT.
- Shows: exercise name, "Set 2 of 3", the rep range; large weight and reps with −/+ (weight by
  the exercise's own `incrementLbs`, reps by 1); a full-width LOG; SKIP; the rest countdown after
  a log; a **ghost set**: last time's numbers in faint text ("Last time 135 × 10").
- **Auto-advance:** after LOG, the view moves to the next unlogged set, then the next exercise
  (TRAIN's own "current exercise" rule); when every set is logged it says so and offers EXIT to
  finish in TRAIN as usual (finishing stays TRAIN's hold-to-confirm).
- **Screen awake:** Screen Wake Lock API while gym mode is open (re-acquired when the page
  becomes visible again); released on EXIT. Does nothing where unsupported.
- **Plate math** (barbell exercises only: custom exercises with `equipment === "Barbell"`): per
  side for a 45 lb bar with 45/35/25/10/5/2.5 lb plates, e.g. "185 lb = bar + 45 + 25 per side";
  "Not loadable with standard plates" when it can't be made exactly.
- **Warm-up ramp** (ruling 3A): before set 1 of the session's first barbell exercise, a
  suggestion line "Warm-up: 45 ×10 · 95 ×5 · 130 ×3 · 155 ×1" (the bar, then ~50/70/85% of the
  working weight rounded to the nearest loadable weight; steps not above the bar dropped). Never
  logged unless Gavin logs those sets himself.
- Pure helpers (plate math, ramp) in `src/application/gymModeQueries.ts`, unit-tested.

## Explicit exclusions

No cue text (GYM-002). No sound or vibration. No change to set/rest/PR rules, templates, the
Engine or the finish flow. No new tab. No change to TODAY, BODY, MORE or Weekly.

## Relevant authority / references

`docs/UX_DECISIONS.md` "Gym mode (owner rulings 2026-10-04)"; TRAIN's one-handed execution (P4),
rest (TRAIN-WAVE-A), PR tag (PR-CARDS-001).

## Required invariants

Every set logged in gym mode goes through the same `logSet` call TRAIN makes; leaving gym mode
loses nothing; the plain TRAIN screen is unchanged when gym mode is off.

## Acceptance criteria

1. GYM MODE opens a full-screen view; EXIT returns to TRAIN with the same session state.
2. LOG records the set exactly as TRAIN would and advances to the next set or exercise.
3. The ghost set shows last time's numbers when they exist.
4. The wake lock is requested on open and released on EXIT (test with a stubbed `navigator.wakeLock`).
5. Plate math and warm-up ramp: unit tests for loadable/unloadable weights and ramp rounding;
   shown only for barbell exercises.
6. Main buttons ≥ 56 px tall; no overflow at 320–412 px; AA contrast (axe).
