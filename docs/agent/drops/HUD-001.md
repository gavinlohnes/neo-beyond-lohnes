# HUD-001 // HUD DESIGN SYSTEM (VISUAL-ONLY)

## Mission

Restyle BEYOND as one HUD visual system, visual-only: pure black #000 ground; ONE red, #D0141B,
replacing the current accent; cut (chamfered) corners on cards and buttons; bracket ticks on
section frames; 1px lines; Chakra Petch for display/body and JetBrains Mono for labels and
numbers, self-hosted. Owner brief 2026-10-04 (Queue item 1). Nothing changes in what any screen
shows or does.

## Approved baseline

`origin/master` at `5538f0f7750905baa8116a54cd9218a23a7be6ec`. Builder: if master moved, set `baseline:` to the fresh
`git rev-parse origin/master` before `factory-drop.mjs init` (the only edit allowed here).

## Risk classification

ARCHITECTURAL: app-wide visual system and new font assets. No Engine, domain, persistence,
schema or behavior change. **Doctrine amendment approved by the owner 2026-10-04 (decision 1A)**;
buildable now. The merge still waits for the owner (Architectural).

## Authorized scope

- `src/ui/styles/tokens.css`: `--bg #000`; `--accent` and every red token → `#D0141B` (one
  red only); 1px border tokens; corner-cut size token (e.g. `--cut: 8px`) applied with
  `clip-path` on cards and buttons; fonts `--font-display/--font-body: "Chakra Petch"`,
  `--font-mono: "JetBrains Mono"`.
- `src/ui/styles/global.css`: cut corners, bracket ticks on section frames (`.equipment-row`,
  `.tool-label` frames) drawn with 1px pseudo-elements, 1px rules.
- Fonts self-hosted under `public/fonts/` (WOFF2, Latin subset) with `@font-face`, plus the
  OFL license files; precached by the service worker. No Google Fonts or other CDN request.
- Every screen: TODAY, TRAIN, BODY, MORE and their sub-screens. **Weekly is excluded** until the
  F1 field-test review: it keeps its current look (scope its styles so the new tokens don't reach
  `WeeklyCheckInScreen`, or keep a Weekly-local token set).
- Text and controls pass **WCAG AA** contrast on #000 (4.5:1 body, 3:1 large text and UI
  components); red text only where it passes, otherwise red is a stroke/fill, not text.

## Explicit exclusions

No emblems, logos, wordmarks, mascots or character names (the existing BEYOND mark stays as it
is; nothing new). No layout, copy, information-architecture, behavior, animation-timing or data
change. No Weekly restyle. No new runtime dependency beyond the two font files.
