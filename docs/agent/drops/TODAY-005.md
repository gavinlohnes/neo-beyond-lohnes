# TODAY-005 // FIELD QUIET LOOP

## Mission

Make TODAY prove one bounded FIELD interaction loop—quiet field, earned existing operation,
truthful deliberate action, mechanical confirmation, recession, and return to the next rightful
field owner—without redesigning TODAY or creating new recommendation, domain, or persistence
authority.

## Approved baseline

`origin/master` at `9b644d6a12257ab4cfed38b80d8cd6579afbd4d6`, verified via
`git fetch origin master && git rev-parse origin/master` before worktree creation.

## Risk classification

ROUTINE. This is a bounded UI/presentation and test change using existing application commands,
semantic primitives, attention policy, and motion tokens. None of the Architectural or High-Risk
triggers apply.

## Authorized scope

- Refine TODAY's existing presentation so a truthful `NO ACTION REQUIRED` state can occupy a
  coherent quiet FIELD without filler.
- Let one legitimately earned existing operation own the field according to the existing
  `attentionPolicy.ts` authority, visually subordinating nonessential support information.
- Use the narrowest existing routine action—prefer hydration only if current contracts support
  it—to prove deliberate action, immediate mechanical confirmation, recession, and return to
  the next rightful field owner.
- Preserve deviations/corrections one layer deeper with no hidden gesture dependency.
- Reuse existing semantic UI, motion, command-surface, and visual-token primitives.
- Add or update focused TODAY tests and perform direct UI inspection, including 320px behavior,
  accessibility, keyboard/focus behavior, and the complete quiet-loop transition.

## Explicit exclusions

- No Engine, recommendation-priority, command/event contract, persistence, schema, migration,
  fixture-compatibility, dependency, or AI behavior changes.
- No second prioritization system, Situation Assembly, generalized ActiveOperation framework,
  persisted state machine, scoring/ranking layer, fake reminder, synthetic domain truth, or
  auto-log behavior.
- No broad TODAY, BODY, TRAIN, or MORE redesign; no Batcomputer, trend/graph, generalized
  personalization, decorative animation, fake telemetry, dashboard expansion, or doctrine edit.
- No merge, integration, Factory closure, or activation of another Drop by the Builder.

## Required invariants

- Existing attention policy remains TODAY's single presentation authority; active operations
  continue to outrank passive attention.
- The Engine remains the sole recommendation authority; prediction never becomes recorded fact
  without an operator action.
- The proving action uses an existing canonical application command and preserves correction
  capability; no hidden gesture, auto-log, guilt, or celebratory completion behavior is added.
- Resolution de-energizes and surrenders the field mechanically, within existing motion and
  reduced-motion conventions.
- Existing navigation, offline/local-first behavior, accessibility, keyboard/focus behavior,
  and 320px mobile usability remain intact.
- No new domain facts are invented to populate quiet or earned states.

## Acceptance criteria

- Focused tests prove TODAY renders a coherent quiet field without filler when no action is
  required.
- Focused tests prove one existing earned operation clearly owns the field and nonessential
  support is subordinate.
- The selected routine action is one deliberate truthful interaction where canonical behavior
  permits; deviation/correction remains accessible.
- Tests prove no prediction is recorded without operator action and the action uses existing
  application/persistence authority unchanged.
- Resolution provides immediate mechanical confirmation, retracts without celebration, and
  reveals the next rightful field owner or `NO ACTION REQUIRED`.
- Existing navigation, accessibility, keyboard/focus behavior, reduced-motion behavior, and
  320px layout remain usable.
- Direct UI inspection confirms the result feels like restrained FIELD/suit equipment rather
  than a competing-card dashboard.
