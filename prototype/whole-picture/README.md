# BEYOND — The whole picture

An original, standalone interactive Review concept. All data and personal stories are fictional. No production files were changed.

## Open

Open `index.html` in a modern browser. It is self-contained, including its fonts, and makes no network requests. No installation or account is needed. If your chat application displays HTML as text, download the file and open it in your browser.

## Explore

1. Change between 28 and 7 days; filter recorded work and off days.
2. Select a day on a chart or in the selector. Open the supporting evidence.
3. Expand measured activity and resting heart rate for more aligned records.
4. Compare work/off contexts or the preceding period. Sparse means abstain below three records.
5. Open a commitment or a reviewed decision to inspect resolution, expectations and outcomes.
6. Choose a demo focus; inspect two illustrative weekly arrangements. Nothing is scheduled.
7. Print or download the demo review. Its JSON is NOT a Beyond backup; do not import it into Beyond.

The focus is held only in page memory. Refresh or Reset clears it. No IndexedDB, accounts, analytics or remote data sources are used.

## Boundaries

This is a design proposal, not a production integration or an approved change to Engine rules, planning semantics, data contracts or doctrine. The view is within COMMAND / Review, not a proposal to replace the app's four primary tabs. The planning section is an optional concept, not an availability inference or a medical recommendation.

## Verification

Chromium interactive checks and axe checks at 320, 390, 768 and 1440 px. See `verification.json` for results. Tests cover the views, evidence dialogs, keyboard selection/return, sparse comparisons, context filtering, focus selection/validation/clearing and reset. No page errors, external network requests or horizontal document overflow observed. Automated accessibility checks do not replace real assistive-technology and device testing.
